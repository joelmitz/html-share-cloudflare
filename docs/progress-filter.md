# 進行中フィルター

ヘッダーの2段目に絞り込みチップを並べ、まだ終わっていない仕事を1つずつチップにします。並びは「すべて」、進行中フィルターの項目の順です。一覧は先頭に「スター」段（スター付きのカードは丸ごと、スター付きのページはそのページだけ）を置き、残りを日付の区切りに並べます。チップで絞り込んだときも、絞った結果に同じ並べ方をします。進行中の段は一覧に置きません。ページ単位ではなく仕事単位なので、ページの無い用件（チャットの返信待ちなど）も載せられます。台帳は設定ファイルの `content.shelf` で、エージェントに「進行中に入れて」「進行中から外して」と頼めば出し入れできます。

```yaml
content:
  shelf:
    - id: demo-review          # 一意なID。✕で外した印はこのIDで覚える
      stream: demo             # チップを押すと一覧をこのテーマに絞る。名前はテーマの streamChip
      note: 数字の出典を確認する
    - id: team-thread
      title: チャットの問い合わせに返信
      url: https://chat.example.com/threads/12345   # ページの無い用件はリンクで
      added: 2026-01-20
      due: 2026-01-24          # url だけの項目の締切（任意）
  streamDues:                  # テーマの期限。進行中フィルターの項目にも、押しピンで足したテーマにも出る
    demo: { 2026-01-24: リハーサル, 2026-01-31: 本番 }
```

期限はテーマごとに `content.streamDues` へ書きます。画面を開くたびに今日以降でいちばん近い日を選ぶので、節目が複数ある仕事は全部並べておくと、リハーサルが過ぎた翌朝に `publish` し直さなくても本番の日へ繰り上がります。進行中フィルターの項目だけでなく、画面の押しピンで足したテーマにも同じ期限が出ます。テーマの項目に `due` を書いても、そのテーマに `streamDues` があれば使いません（`publish` で警告します）。期限の無いテーマは書かないか、`{}` にします。

チップの名前はテーマごとに `content.pages` の `streamChip` で決めます。同じテーマのどれか1ページに書けば足ります。

```yaml
content:
  pages:
    - path: reports/weekly-2026-01-12.html
      stream: weekly-report
      streamLabel: 週次レポート（チーム全体の進捗まとめ）   # 一覧の見出し
      streamChip: 週次レポート                              # 進行中フィルターのチップに出す短い名前
```

- チップ名は全角1・半角0.5で数えて11までに収めます（「Q3ロードマップ説明会」で10）。長すぎるテーマと、`streamLabel` があるのに `streamChip` が無いテーマは、`publish` の時点で警告します（公開は止めません）
- `streamChip` が無ければ `streamLabel`、それも無ければ `stream` をそのまま出します
- テーマの項目は `title` を書かなければテーマのチップ名を使います。`url` だけの項目は `title` を書き、無ければ `id` を出します

- 並びは、設定ファイルの項目も押しピンで足したテーマも合わせて締切の近い順です。締切の無い項目は後ろへ回ります
- チップには名前と残り日数（「今日」「明日」「5日」。3日以内は強調色）を出します。締切の無いテーマは数字を出しません
- 期限の最後の日の翌日を過ぎた項目と `done: true` の項目は、進行中フィルターから外れます。押しピンで足したテーマは期限を過ぎても外さず、数字だけ消えます
- テーマ（`stream`）のチップを押すと、一覧をそのテーマのページだけに絞り込みます。畳まれていた版も全件出ます。同じチップをもう一度押すか「すべて」で解除します
- チップは押しても外部のページへは飛びません。リンク（`url`）だけの項目も、押すと絞り込みの表示に切り替わります
- 絞り込み中は本文の先頭に、名前・締切（「あと5日・1/31（土） 本番」）・メモ・ページ数を1行で出します。項目に `url` があれば、同じ行に「元のスレッド ↗」を添えて新しいタブで開けるようにします。`stream` と `url` は1つの項目に両方書けます
- 選択中のチップの右端の ✕ で進行中フィルターから外すと、その印は本人設定（`shelfDone`）としてPCとスマホで共有されます。設定ファイルとページはそのまま残ります
- 進行中へ足す・外すは、テーマのカード見出し（テーマ名・件数・進行中へ入れるボタン・☆）の ☆ の左にある「進行中へ入れる」ボタンで行います。未登録は枠に＋、登録済みは塗りに✓で、もう一度押すと外します。チップで絞り込めばそのテーマのカードだけが出るので、外すときも探しやすくなります。足したテーマはテーマのチップ名と、`streamDues` にあれば直近の期限を出します（本人設定 `shelfAdded`）。設定ファイルにあって外していた項目なら、外した印を消して締切ごと戻します。設定ファイルにあるテーマは、外した後も「自分で足したテーマ」としては出しません。カード見出しには更新時刻を出しません（各行に出ているため）
- リンク（`url`）だけの項目のようにカードを持たない項目も、チップを選んで ✕ で外せます。設定ファイルで `done: true` にするか、`due` の経過でも消えます
- `shelfDone` と `shelfAdded` は足す・外すの両方向があるので、端末間では保存された値を正とします
- 検索中と削除済みの表示ではチップを出さず、絞り込みも解除します
- PCではチップを折り返し、スマホ幅では横スクロールで並べます
