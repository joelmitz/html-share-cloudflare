# リンクプレビュー（OGP）

共有URLをSlack・Teams・Xへ貼ったとき、素っ気ないURLではなくカードで表示されます。

| 出るもの | 中身 |
|---|---|
| アプリ名 | `content.siteName`（省略時は `#HTML共有くん`） |
| ページ名 | 設定の `title`、無ければHTMLの `<title>` |
| 説明文 | ヒーローのリード文（`<p class="sub">`）→ `lead` → 最初の段落の順に拾う |
| 画像 | 同梱のカード画像（`assets/og-card.jpg`）。`content.ogImageUrl` で差し替え、`false` で出さない |
| カードの大きさ | `content.ogCardType`（省略時は `summary`＝各媒体でいちばん小さいカード） |

画像は次の3通りです。

- **同梱の画像（既定）**：publish が配信先の `/og/card.jpg` へ置き、全ページのカードに使います。
  配信面は署名付きURLでしか開けませんが、`/og/*` だけは署名なしで開ける設定にしてあるので、
  クローラーも画像を取れます。置くのはこの1枚だけで、ページの中身は `/og/` に置きません
- **自前の画像**：`content.ogImageUrl` に絶対URL（https）を書くと、そちらを使います。
  `siteName` を変えたときは、画像の中のアプリ名と揃うようにこちらで差し替えてください
- **画像なし**：`content.ogImageUrl: false` にすると `og:image` を出しません。
  SlackとXはテキストだけのカードになり、**Teamsは`og:image`が無いとカードを出しません**

既存の環境で同梱の画像を使い始めるには、`deploy`（`/og/*` の配信ルールを足す）と
`publish` の両方が要ります。

ページが自分で `og:title` を持っている場合は、そのページには何も足しません。

## 画像を置くときの注意

**`og:image` はページ本体とは別のリクエストで取りに来ます。タグが正しくても、画像だけ落ちます。**
しかも落ちたことは表に出ず、**Xは大きいカードを諦めて小さいカードへ縮む**だけなので、
「なぜかOGPが出ない」に見えて原因がHTML側にありません。

- **画像URLを直接叩いて、`200` かつ `Content-Type: image/*` が返ることを確かめる。**
  S3 + CloudFront OAC は「オブジェクトが無い」を **404 ではなく 403** で返すので、
  権限の問題だと読み違えやすい
- **`Cache-Control: immutable` を付けない。**「中身は永久に変わらない」の宣言になり、
  画像を差し替えてもクローラーが取り直しません。`public, max-age=3600` 程度が無難
- **差し替えたら、URLの末尾に `?v=20260920` のようなクエリを足す。**
  SNSは画像をURLの文字列で覚えるので、ファイル名が同じままだと古い画像が出続けます。
  **ファイル名のほうを変えると、既存の投稿が参照している画像が消えます**
- **正方形の画像は、要素を中央の横帯に収めて描く。** 同じ画像でも、パソコン版のSlackは
  小さな正方形のサムネイルで、スマホ版のSlackは横長に切り抜いた大きな画像で出します。
  クローラーは1回しか取りに来ないので、表示先ごとに画像を出し分けることはできません。
  上下いっぱいに文字を積むと、スマホ版で上下が詰まって見えます。アプリ名は1行にし、
  上下に余白を残すと、どちらの表示でも収まります
- **`robots.txt` でクローラーを止めない。** 検索インデックスからの除外は `X-Robots-Tag` と
  `<meta name="robots">` が担っています。`Disallow: /` を置くと Slack / Teams / X の
  クローラーまで巻き添えになります
- SVGは使えません。JPEG か PNG を置いてください

## カードの大きさ

既定は `summary`（各媒体でいちばん小さいカード）です。**画像を指定しても大きくなりません。**

```yaml
content:
  ogCardType: summary_large_image   # 横長の大きなカードにしたいときだけ
```

`summary_large_image` は **1200×630 前後の横長画像**を前提にした見せ方です。
正方形やロゴを渡すと引き伸ばされます。ページごとに別々の画像を用意しない運用では、
小さいカードのほうが収まりよく見えます。

> メタタグは `<meta charset>` の後ろへ入れています。日本語のページ名が文字コード宣言より前に出ると、
> クローラー側が文字化けすることがあるためです。
